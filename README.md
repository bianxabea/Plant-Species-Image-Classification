# Plant-Species-Image-Classification

---

## A. Project Review

### 📄 Brief description of the project

The project focuses on the classification of **herbal plants** through image recognition technology, specifically emphasizing the collection and preparation of a comprehensive dataset consisting of different varieties of medicinal herbs. The primary objective of this study is to gather high-quality images of selected herbal plants such as Butterfly Pea (Clitoria ternatea), Katakataka (Bryophyllum pinnatum), Lemon Verbena (Aloysia citrodora), Sage (Salvia officinalis), Roselle (Hibiscus sabdariffa) and many more.

### 🎯 Purpose of the image classification model

The purpose of the image classification model is to automatically identify and classify different herbal plants based on their visual features such as leaf shape, color, and texture. It uses a trained dataset to accurately recognize selected medicinal herbs, making plant identification faster and more reliable for educational and research purposes.

## Reflection Questions

### 1. How did the number of images per class affect your model’s accuracy?

The number of images per class directly affected the model’s accuracy. Classes with fewer images resulted in lower accuracy because the model had limited data to learn their features, leading to misclassification. In contrast, having an equal and larger number of images per class improved the model’s ability to recognize patterns and differences among the herbal plants, resulting in higher accuracy and better overall performance.

### 2. Which plant species were most commonly misclassified and why?

None of the plant species were commonly misclassified. The model was able to correctly distinguish all classes with minimal or no confusion. This suggests that the dataset was balanced and that each plant species had clear and distinct visual features, allowing the model to achieve high accuracy.

### 3. How did changing the epochs, batch size, or learning rate affect the training results?

Changing the epochs, batch size, and learning rate had a noticeable effect on the model’s training results. Increasing the number of epochs allowed the model to learn more from the dataset, which improved accuracy; however, too many epochs caused overfitting, where the model performed well on training data but poorly on new data. Adjusting the batch size affected the stability of learning—smaller batch sizes improved generalization but increased training time, while larger batch sizes made training faster but sometimes reduced accuracy. 

### 4. What challenges did you encounter during dataset collection and labeling?

- Collecting enough images for each plant species was time-consuming.
- Ensuring consistent image quality and angles was difficult, especially for plants with small or similar features.
- Labeling errors were possible if plants looked similar or if I accidentally misfiled images into the wrong class

### 5. If you were to improve your model, what specific changes would you make and why?If you were to improve your model, what specific changes would you make and why?

If I were to improve the model, I would increase the number of training images for each plant species to provide more data for the model to learn from. I would also ensure that the dataset is balanced by having an equal number of images per class to prevent bias during classification. Additionally, I would collect images with different lighting conditions, angles, and backgrounds to improve the model’s ability to generalize in real-world scenarios. Applying data augmentation techniques such as rotation, flipping, and zooming could further enhance the diversity of the dataset. Lastly, adjusting training parameters such as the number of epochs or batch size may help improve the model’s learning performance and overall accuracy.
